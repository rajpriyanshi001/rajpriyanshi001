## 🔨 What I'm building

### 🎓 [PaperMate AI](https://github.com/rajpriyanshi001/Research-Paper-to-Presentation-Viva-Assistant)
Upload a research paper and PaperMate gives you a structured summary, a ready-to-edit PowerPoint deck, plain-English explanations of the hard concepts, and a mock viva with the questions an examiner is likely to ask.

Under the hood it's a multi-agent pipeline:
- An **intent router** decides which agent should handle your request
- **RAG with ChromaDB** retrieves the relevant paper sections, with page-level citations
- A **reflection step** checks every answer against the retrieved text to catch hallucinations
- Built with **LangChain (LCEL), Gemini, Streamlit and python-pptx**

I built this because reading papers as a student is painful, and I wanted to see how far grounded, citation-backed answers could go.
